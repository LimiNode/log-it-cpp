Detailed Description

Exposes log metrics as Prometheus text exposition format via user-provided callback.

This backend tracks internal counters and gauges (log records total, dropped, failed exports, last log timestamp, time since last log) and serializes them to Prometheus text exposition format. The payload is passed to a user-provided callback on wait() or on-demand via collect_payload().

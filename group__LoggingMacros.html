Detailed Description

A collection of macros for streamlined logging operations.

This group includes macros for logging messages at various levels, adding loggers, managing log settings, and controlling loggers.

Examples

LOGIT_INFO("This is an informational message");
LOGIT_WARN("This is a warning message");

System Error Logging
Use LOGIT_PERROR_<LEVEL> on POSIX and LOGIT_WINERR_<LEVEL> on Windows to automatically attach decoded system error codes to your message. The cross-platform LOGIT_SYSERR_<LEVEL> macro aliases to the appropriate variant.
int fd = ::open("missing.cfg", O_RDONLY);
if (fd == -1) {
LOGIT_SYSERR_ERROR("Failed to open configuration");
}

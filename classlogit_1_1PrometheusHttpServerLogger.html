Detailed Description

Serves Prometheus metrics via an embedded HTTP server.

This backend starts a Simple-Web-Server HTTP server and serves Prometheus text exposition format on the configured path (default: /metrics). It tracks the same internal counters and gauges as PrometheusPayloadLogger.
